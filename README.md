# 🛒 QuickCart – Grocery Delivery Landing Page (E-Commerce Frontend)

A modern, responsive, and production-style **Grocery Delivery & E-Commerce Frontend Project** built with React and Tailwind CSS.
This project started as a landing page and has been upgraded into a full multi-page e-commerce experience.

---

## 🚀 Live Demo

🔗 https://salama5600.github.io/quickcart-landing-page/

---

## 📌 Overview

QuickCart is a fully responsive frontend project that simulates a real grocery delivery platform.
It includes multiple pages, routing, authentication UI, shopping cart system, and modern UX/UI interactions.

The goal of this project is to demonstrate **real-world frontend development skills** suitable for freelance work and portfolio presentation.

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Salama5600/quickcart-landing-page.git
```

Navigate to project folder:

```bash
cd quickcart-landing-page
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

---

## 🚀 Deployment

This project is deployed using **GitHub Pages**.

To redeploy:

```bash
npm run deploy
```
